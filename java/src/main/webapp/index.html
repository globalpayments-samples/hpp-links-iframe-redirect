Single-use tokenization

Generate a payment reference without charging the card. Your backend later charges that reference once via the GP API SDK.

scope PMT_POST_Create_Single event token-success

How it works

  1. Backend mints an access tokenLimited PMT_POST_Create_Single scope, returned to the page.
  2. Drop-In UI tokenizes the cardCard is captured inside the secure iframe.
  3. token-success firesYou receive a single-use paymentReference.
  4. Backend charges the referenceOne charge via the GP API SDK — token then expires.

Webhook notifications

        
Set notifications.status_url in your transaction payload to receive real-time GP API events. Verify every signature before processing.

      

      

        POST /webhook
        header X-GP-Signature
      

    


    

      

        
Handler

        

          
          Always verify X-GP-Signature (HMAC-SHA256 with your webhook secret) before trusting any payload.
        

        

          

            Node webhook.js
            
          

          
// Production webhook handler
app.post('/webhook', express.raw({ type: 'application/json' }), (req, res) => {
  const signature = req.headers['x-gp-signature'];
  const expected  = crypto
    .createHmac('sha256', process.env.GP_WEBHOOK_SECRET)
    .update(req.body)
    .digest('hex');

  if (signature !== expected) return res.status(401).send('Unauthorized');

  const event = JSON.parse(req.body.toString());
  switch (event.type) {
    case 'TRANSACTION_CAPTURED': handleCapture(event.content[0]); break;
    case 'TRANSACTION_REVERSED': handleReversal(event.content[0]); break;
  }
  res.status(200).send('OK');
});
